## Orden de lectura

1. **Manual de usuario** si tu trabajo es atender el sitio y cargar contenido.
2. **Manual de operación** si además mantienes la instalación publicada.
3. **Despliegue** cuando necesites los comandos exactos o resolver un problema del hosting.
4. **Verificación** para conocer el estado de la última publicación.

El [README del proyecto](../README.md) resume el stack, las rutas públicas y los comandos de desarrollo.
